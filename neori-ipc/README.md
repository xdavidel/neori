# neori-ipc

Types and helpers for interfacing with the [neori](https://gitlab.com/xdavidel/neori) Wayland compositor.

This crate is primarily used by `neori` itself (for IPC), but can also be used by third-party programs.

## Usage

Add this to your `Cargo.toml`:

```toml
neori-ipc = "=0.3.2"
```
